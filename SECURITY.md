# Security Policy

## Supported versions

Mariana is currently distributed as a prerelease. Security fixes are applied to the latest prerelease on the active development branch; older prereleases are not supported.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, private paths, or reproducible exploits in a public issue.

Use **Report a vulnerability** from this repository's GitHub Security tab when it is available. If private vulnerability reporting is unavailable, contact the repository owner privately through their GitHub profile before sharing sensitive details.

Include the affected Mariana version, operating system, impact, reproduction steps, and any suggested mitigation. Remove tokens, cookies, signed URLs, personal paths, and other secrets from logs or screenshots.

The maintainer will acknowledge a complete report when practical, validate its impact, and coordinate disclosure after a fix or mitigation is available.
