# Completing a Mariana command

Place the cursor on the word you want to finish. For example, enter `dj cro`, press Tab, then type a crossfader value from 0 to 100. When entering `tone sweep 220 880 --cur`, Tab offers `--curve`. The existing track, frequencies and other arguments stay in place.

| Surface | How to use it |
| --- | --- |
| Mariana CLI in PowerShell, Bash or another interactive terminal | Start Mariana and type at its prompt. Tab inserts a suggestion. If Enter offers a correction, review the suggestion, press Tab to accept, and then Enter to run the edited line. Use Escape to keep your original text. |
| Full-screen TUI | Start `python main.py --tui`, press **:**, and use the same editor and Tab control. Ctrl+K searches the command palette and Ctrl+R searches history. F6 opens the command directory. |
| Electron | Use the embedded Mariana terminal for commands. The separate **Explore commands** control lets you browse command spellings without modifying your current terminal input. |
| Portable Console and Flow, Android/iOS phone player | Use the command field. In Flow choose **Commands**. Tap a match or use Tab/Shift+Tab to cycle options. Ctrl+Space requests suggestions and Escape closes them. Ctrl/Cmd+K opens the command field. Select **History** or press Ctrl+R in the field to find previously submitted commands in this tab. |
| Paired native browser | Start `web session` in Mariana and connect. The paired field requests native command syntax from the running player. Use **History** for this tab’s submitted commands. The running host reviews non-transport commands. |
| Watch previews | The watch interfaces provide playback and practice controls. Their UI has no general Mariana command field. |

## What the suggestions cover

Commands are scoped to the player handling them. For example, the native command `dj mixxx` can launch a local application. The portable mixer offers its own output and export commands. The native engine combines the command catalog, alias table, additional literal paths, option metadata and parameterized command heads. The web build exports the portable routes. Both grammar files are packaged with the native executable.

The editor matches commands, aliases, subcommands, flags and supported values at the cursor. It can offer a correction for a nearby spelling, including a transposition. Accepting a suggestion edits the input. Execution uses the player’s regular Run or Enter action and any confirmation the command normally requests. Retired routes retain their existing guidance. Guesses never supply a confirmation switch.

The native player can suggest known local values in supported argument positions, including media indexes, saved playlists, Strudel projects and local paths. The portable player uses data already available to that browser. The paired browser receives static command syntax without a directory listing or the host’s private history. Free-form titles, singer names, room IDs and URLs are entered as supplied. Ambiguous input can yield several alternatives or no correction.

## Quick checks

| Enter | Expected behavior |
| --- | --- |
| `dj cro` then Tab | Completes `crossfade`. |
| `dj cue A ` | Offers the operations for deck A, including `set` and `go`. |
| `tone sweep 220 880 --cur` then Tab | Completes `--curve`. The next argument offers `linear` and `log`. |
| `karaoek status` then Enter | Offers `karaoke status`. Review and accept before running it. |
| `librivox search "My Book" --limti 3` | Offers `--limit` and preserves the quoted title and the number. |
| `artist search SuggaHoney` in native Mariana | Leaves the artist’s spelling intact. |

Web assets are regenerated by `python tools/build_web_player.py --serve --view flow --open`. Restart a running player after applying the patch. A packaged phone or Electron app needs a fresh build to pick up source changes.
